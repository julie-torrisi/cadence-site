# Cadence

**A third-party AI agent, built to teach Figma your design system.**
Figma plugin · coming soon to Figma Community.

🔗 **Live site:** https://julie-torrisi.github.io/cadence-site/

Describe any message your product needs to send its users, from a feature launch to an error to a policy change. Cadence designs it for iOS, Android and web from your own components, then tells you if it's ready or who needs to see it first.

## How it works

1. **Describe.** Write the message in plain words. Cadence works out what kind it is (11 message types).
2. **Design.** It picks where the message goes and how loud to be, then builds layered, editable frames from your published library.
3. **Review.** A review agent checks every frame against your rules: ready to publish, needs review by a named team, or fix needed. AI suggests, people decide.

## Built for someone else's platform

Cadence runs inside Figma, next to Figma's own AI, so it is designed to be a good guest:

- **Clear attribution.** Everything it makes lands in one section named "Cadence · [your message]".
- **Scoped access.** It reads only the libraries and assets you point it at.
- **Visible handoffs.** When a message needs a person, it names the team and the reason.

## This repo

The source for the Cadence site, including the interactive concept prototype (fictional launches, built on [figma/sds](https://github.com/figma/sds) tokens). Plain HTML, no build step, hosted on GitHub Pages.
